# 시각 회귀 검사

[English](visual-regression.md)

HWPX 패키지 검증은 두 오피스 프로그램이 같은 줄바꿈과 같은 쪽 픽셀을 만든다는 것을
증명하지 못합니다. 그래서 `visual-check`는 HWPX 렌더러인 척하지 않고, 일부러 PNG
쪽 이미지를 입력으로 받습니다.

## 권장 절차

1. 고정된 JSON fixture로 HWPX를 만듭니다.
2. 신뢰할 수 있는 오피스 렌더러 하나와 고정된 글꼴로 열어서 내보냅니다.
3. 쪽을 `page-001.png`, `page-002.png` 순서로 기준 폴더에 저장합니다.
4. 비교할 버전으로 같은 작업을 반복해 현재 폴더에 저장합니다.
5. 두 폴더를 비교합니다.

```bash
python -m pip install -e ".[visual]"
exam-hwpx visual-check baseline-pages current-pages \
  --max-changed-pixel-ratio 0.001 \
  --pixel-delta-threshold 8
```

PowerShell에서는 위의 줄 이음 문자 대신 백틱(`` ` ``)을 쓰거나, 명령을 한 줄로
쓰면 됩니다.

비교하려면 쪽 파일 이름과 크기가 같아야 합니다. 회색조 차이가 임계값을 넘는
픽셀을 "바뀐 픽셀"로 셉니다. 바뀐 픽셀 비율이 설정한 한도를 넘으면 그 쪽은
실패입니다.

## 기준선과 함께 기록할 것

- 렌더러 이름과 정확한 버전
- 운영체제와 버전
- 설치된 글꼴 이름과 버전
- 내보내기 해상도와 색상 모드
- 원본 JSON의 SHA-256과 생성된 HWPX의 SHA-256
- 기준선을 승인한 사람 또는 CI 작업

실제 학생 정보, 저작권이 있는 시험 자료, 비공개 브랜딩, 이미지 재배포가 제한된
글꼴이 담긴 렌더링 결과는 커밋하지 마세요.

## 결과 해석

이미지 비교 통과는 제공한 래스터 쪽이 임계값 안에 머물렀다는 뜻일 뿐입니다. HWPX
표준 준수, 접근성, 정답의 정확성, 콘텐츠 사용 권리를 보증하지 않습니다.
