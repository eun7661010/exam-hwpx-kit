# 시험 JSON 스키마 v1

[English](schema.md)

기계가 읽는 정본 계약은
[`exam-paper.v1.schema.json`](../src/exam_hwpx_kit/schemas/exam-paper.v1.schema.json)입니다.
`tools/export_schema.py`가 Pydantic 모델에서 이 파일을 다시 만듭니다. CI는 파일을
재생성한 뒤 커밋되지 않은 차이가 있으면 실패 처리합니다.

## 루트 필드

| 필드 | 필수 | 의미 |
|---|---:|---|
| `schema_version` | 예 | 반드시 `exam-hwpx-kit/v1`이어야 합니다. |
| `title` | 예 | 문서 제목, 1~200자. |
| `layout` | 아니오 | A4 여백, 한 단 또는 두 단, 단 간격, 정적 줄 수 예산. |
| `assets` | 아니오 | 상대 경로 PNG/JPEG 이미지. 자산 ID는 중복될 수 없습니다. |
| `blocks` | 예 | 순서가 있는 지문·문항 블록. |

알 수 없는 필드는 거부합니다. 오타가 조용히 무시되는 일을 막기 위해서입니다.

## 지문 블록

지문에는 `id`, 화면에 보이는 `label`, 흐르는 본문 `text`, `question_ids`가 있습니다.
참조한 문항은 모두 존재해야 하고 지문보다 뒤에 나와야 합니다. 한 문항을 여러
지문이 참조하는 것은 사용자의 작업 흐름이 허용할 때만 의미가 있으며, v1은 지문 간
재사용을 금지하지 않습니다.

## 문항 블록

문항에는 고정된 `id`, 양의 정수 `number`, `stem`, 2~5개의 순수 선택지 문자열,
선택 사항인 `points`, 보기 `boxes`, `image_ids`, 그리고 `keep_together` 의도가
있습니다. 선택지 앞에 `①`~`⑤`를 붙이지 마세요. 렌더러가 그 표시를 정확히 한 번
붙입니다.

## 자산

자산 경로는 JSON 파일이 있는 폴더를 기준으로 해석합니다. Windows·POSIX 절대 경로는
거부합니다. 해석된 경로는 심볼릭 링크를 풀어낸 뒤에도 그 폴더 아래에 있어야 합니다.
지원 확장자는 `.png`, `.jpg`, `.jpeg`입니다.

`alt` 필드는 필수입니다. HWPX v0.1은 아직 이 값을 그림 개체에 기록하지 않지만,
원본 계약에 남겨 두면 접근성 정보가 유실되지 않고 앞으로 형식 고유 필드에 대응할
여지가 생깁니다.

## 정적 오버플로 위험

`max_lines_per_column`은 실제로 측정한 쪽 높이가 아닙니다. 생성 전에 분명히
너무 큰 분리 방지 문항을 잡아내기 위한 결정적이고 보수적인 예산입니다. 글꼴 지표와
실제 쪽 나눔은 신뢰할 수 있는 렌더러가 필요합니다.

## 버전 관리

필수 필드를 추가하거나 기존 의미를 바꾸려면 새 `schema_version`이 필요합니다.
새 선택 필드는 기존 `extra=forbid` 동작 아래에서 옛 소비자가 분명히 거부할 수 있을
때만 추가할 수 있습니다. 버전 이전은 명시적으로 해야 하며, CLI는 절대 추측하지
않습니다.
