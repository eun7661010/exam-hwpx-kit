# 보안·개인정보 모델

[English](security-model.md)

## 보호하는 경계

- 자산 경로는 JSON 파일 기준 상대 경로여야 합니다.
- 해석된 자산 경로는 JSON 폴더 아래에 있어야 합니다.
- 없는 파일, 지원하지 않는 이미지 확장자, 안전하지 않은 제어 문자는 생성을 막습니다.
- 영수증에는 절대 입력·출력 경로가 아니라 파일 이름과 해시만 들어갑니다.
- CLI는 네트워크 요청, 문서 업로드, 원격 측정, LLM 호출을 하지 않습니다.
- 예제와 생성 자산은 합성 자료이며 저장소의 스크립트로 재현할 수 있습니다.

## 위협 모델 밖

- 본문이나 픽셀 안의 모든 개인정보를 찾아내는 것
- 입력 콘텐츠의 저작권 귀속이나 재배포 허가 여부를 판정하는 것
- 이미지 파일의 바이러스·악성코드 검사
- 정답 숨김, 문서 암호화, DRM, 전자서명, 시험 배포 보안
- 픽셀 단위로 동일한 렌더링, 특정 오피스 버전에서 열린다는 보증
- 이미 침해된 호스트에서 CLI를 실행하는 시스템을 보호하는 것

출처와 공개 권리가 확인되기 전까지 모든 시험 JSON과 이미지를 민감 자료로 다루세요.
fixture를 공개하기 전에 비밀 정보와 개인정보 검사를 실행하세요.
